# Початкова матриця простежуваності PageTracker

**Версія:** 0.2
**Призначення:** зв’язати вимоги SRS з критеріями прийняття, BDD-сценаріями та плановими тікетами. У колонці «Тікет» наведено повний ланцюжок робіт: `TEST → GATE → FEAT → VER → VAL`; `GATE` є лише людським рішенням про перехід.

Позначка `—` у BDD означає, що окремий сценарій ще не сформовано.
