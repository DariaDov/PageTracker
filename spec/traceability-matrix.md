# Початкова матриця простежуваності PageTracker

**Версія:** 0.1
**Призначення:** зв’язати вимоги SRS з критеріями прийняття та наявними BDD-сценаріями. Колонки тікетів, тестів, коду й документації залишено порожніми для заповнення під час реалізації.

Позначка `—` у BDD означає, що окремий сценарій ще не сформовано.
