# Інформаційна системи: PageTracker

## 1. Основна ідея та призначення
Система призначена для відстеження прочитання кількості сторінок книги. Система буде допомагати відстежувати кількість прочитаних сторінок за день, а також початок та завершення прочитання книги. Важливо, що система сама буде розраховувати кількість прочитаних сторінок за добу, усе що вимагається від користувача - це ввести номер початкової сторінки та кінцевої. Після на основі цих даних будуть формуватися середні значення кількості прочитаних сторінок за тиждень, місяць та рік.

## 2. Ключові функції (High-level features)
* Авторизація користувача у своєму аккаунті.
* Створення, редагування та видалення кількості прочитаних сторінок у певний день.
* Розрахунок середніх значень за певний проміжок часу.

## 3. Цільова аудиторія
Продукт орієнтований на персонального користувача.

## 4. Очікуваний технологічний стек
* Backend: Node.js / Python
* Frontend: React / HTML+CSS+JS
* Database: PostgreSQL
